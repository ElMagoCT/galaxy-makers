# Galaxy Makers (fast rebuild)

A static, no-build rebuild of [galaxymakers.org](https://www.galaxymakers.org/), the
Durham University / ICC outreach exhibit where you "create a universe" and watch the
EAGLE simulation respond. All movies, plots, images and text are theirs; this rebuild
only changes how the site is delivered.

## Why it was slow

The original "Simulating..." screen never simulated anything:

- `mycarousel.js` hid the results behind a hard-coded `setTimeout(showFirst, 10000)`:
  a fixed 10-second wait on every run.
- Each run was a PHP round trip (1-2 s) that returned every sub-page at once, with eight
  `preload='auto'` videos (about 5 MB) plus 2 MB PNGs, jQuery, two Bootstrap versions,
  Google Fonts, reCAPTCHA, a Twitter widget and Google Analytics.
- "Make a random universe" was broken outright: the server truncated the page at 4 KB, so
  the spinner never ended.

The results are a lookup table: dark matter -> L/M/H, black-hole power -> L/M/H, and the
share of high-mass stars -> L/M/H pick one of 27 pre-rendered EAGLE runs.

## How this version works

- `assets/js/app.js` does the same lookup in the browser. Results appear instantly.
- Only the sub-page you are reading has media in the DOM; videos use `preload=metadata`,
  the hologram version loads only when you switch to it, and the next page's movie is
  prefetched while you read.
- No frameworks, no fonts, no third-party scripts. The pie chart is a CSS conic gradient;
  the before/after slider is a range input over two images.
- Galaxy PNGs were re-encoded as JPEGs (2.6 MB -> 0.45 MB each).
- Shareable URLs and codes: a universe is `U<dm>-<agn>-<low>-<medium>-<high>` (for example
  `U84-2-40-35-25`), a galaxy is its name (`spiral`). The old exhibit codes were server-side
  and could not be recovered.

Scoring reproduces the original within +/-1 point (fitted against 119 samples; see
`tools/fit.py`): distance from the real Universe (84 % dark matter, medium black-hole
power, a 40/35/25 star mix) with an 18-point penalty for the wrong black-hole setting.

## Layout

- `index.html`, `universe.html`, `galaxy.html`, `code.html`, `about.html`, `credits.html`,
  `holograms.html` - generated by `tools/build_pages.py` (shared header/footer).
- `assets/js/data.js` - all page text, generated by `tools/extract.py` + `tools/gen_data.py`
  from the original pages.
- `content/universe/` - 27 runs x (8 movies + 4 plots). `content/galaxy/<type>/` - 7 types.

Preview: `python3 -m http.server 8797` in this folder, then open http://localhost:8797/.
